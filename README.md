# Power BI | Estudos e relatórios

Coleção de materiais de um estudo de caso em Power BI, com template e relatórios exportados.

**Data Science** · Dashboards e relatórios

[← Data Science, IA e Automações · Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Apresentar o resultado visual da análise e disponibilizar um ponto de partida para explorar o relatório no Power BI.

## O que você encontra

- Template do estudo de caso em formato PBIT.
- Relatórios em PDF para leitura sem instalar o Power BI.
- Materiais organizados para consulta do estudo.

## Tecnologias

Power BI · PBIT · PDF

## Como explorar

Comece pelos PDFs listados acima. Para explorar o template, abra estudo_caso1.pbit no Power BI Desktop e configure as fontes de dados solicitadas pelo arquivo.
